# Security policy

## Supported versions

No product release has been published. The current `main` branch is the repository's supported foundation line after the bootstrap work order is merged.

## Reporting

Do not post credentials, tokens, private keys, or exploit-sensitive details in issues, pull requests, logs, or screenshots. Report suspected vulnerabilities through GitHub's private vulnerability reporting feature. Remove secrets from any reproduction.

## Current baseline

GitHub secret scanning and push protection are enabled. Dependency vulnerability alerts and Dependabot security updates are enabled. Repository Actions use read-only default workflow permissions and SHA-pinned actions. Product-specific security requirements remain `TBD` until MVP planning.
